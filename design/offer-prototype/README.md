# Offer · 界面改版原型（精修版）

简历诊断 Agent 的新界面设计稿，可直接在浏览器里点击体验。**只是设计原型，不改动 `frontend/` 和 `backend/` 的任何代码。**

网页端和手机端是同一份页面：窗口宽度不超过 720px 时自动切换成手机布局（底部标签栏、单列、对话框从底部弹出）。

## 怎么打开

```bash
cd design/offer-prototype
python3 -m http.server 8080
```

- 网页端：<http://localhost:8080/>
- 手机端预览（带手机外框）：<http://localhost:8080/phone.html>
- 直接进入某一页：`index.html?step=1`～`5`（首页 / 选择岗位 / 匹配结果 / 模拟面试 / 记录）

也可以直接双击 `index.html` 打开，但浏览器会拦截本地字体，中文会退回到 Noto Sans SC，所以建议用上面的命令。

## 设计要点

- 名称与图标：Offer，缺口圆环 + 小星
- 风格：浅色液态玻璃（半透明渐变、背景模糊、高光描边），主色为浅蓝紫，强调色为浅杏
- 字体：Inter（英文与数字）+ 霞鹜新晰黑 LXGW Neo XiHei（中文）；只有页面标题、首页大标题和关键数字加粗
- 布局：左侧图标导航；页面用 8 / 4、5 / 7 两栏栅格，左右等高；间距 24 / 20 / 16 / 12 / 8，字号 36 / 22 / 17 / 14 / 12

## 哪些是真实规则、哪些是演示

- 与线上一致：上传格式（PDF、DOCX、PNG、JPG，单个不超过 15MB）、PDF 最多 10 页、5 轮模拟面试、最近一次匹配结果在浏览器保存 24 小时；岗位职责、任职要求和投递链接整理自 `backend/catalogue/jobs.v1.json`
- 仅为演示：简历解析和岗位匹配是短暂等待后给出固定结果；语音输入会插入一句示例文字；截止日期、通知和「记录」页里 11 月 1 日之前的条目是示例数据
- 「记录」页是新设计：线上目前只保存最近一次匹配，要做历史记录需要后端支持
