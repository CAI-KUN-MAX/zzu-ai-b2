# Embedding 差距与下一迭代建议

评估日期：2026年10月25日。本文仅为可行性调查，未安装向量模型、未调用向量 API、未修改匹配算法，也未产生新的效果或延迟实测结果。

## 当前差距

现有基础评分使用关键词边界匹配、字符 2-gram 余弦相似度和学历规则；前八份再用 LLM 精排。字符相似度依赖表面字串重合，不能称为 Embedding 语义匹配。LLM 诊断也不等于已实现向量召回。

引入 Embedding 应作为单独的匹配迭代：把 JD 与简历文本转成向量，再用向量相似度辅助排序。它不能单独证明技能是否存在、学历是否达标，不能直接把余弦分数当成百分制岗位匹配度。原有命中/缺失、证据校验和可用的降级链路应保留。

## 两个可行方向

| 项目 | 本地 BAAI/bge-small-zh-v1.5 | 智谱 Embedding-3 接口 |
|---|---|---|
| 已核实规格 | 官方列出 24M 参数、权重约 95.8MB，支持 CPU 推理 | 官方提供文本向量接口，支持自定义 256–2048 维 |
| 部署体积 | 权重之外还有 tokenizer 和运行依赖，不能把 95.8MB 当作完整安装体积；尚未实测 | 不在应用服务器加载向量模型，增加请求及向量处理代码即可；具体依赖增量待验证 |
| 内存 | 模型、运行时和中间张量均占内存，运行内存不能等同于权重大小；当前服务器还运行 OCR，须先做并发内存测试 | 模型内存在服务商侧，本机仍需承担文本、网络缓冲和向量缓存 |
| 延迟 | 需测冷启动、每段编码耗时及 20 份简历吞吐，不引用通用硬件榜单替代本机测试 | 需测网络和限流影响、超时与重试；不能仅用服务商宣传估计整批完成时间 |
| 费用 | 本地推理没有该模型的逐次 API 调用费，但有资源、下载和运维成本 | 2026-10-25 官方页面显示 0.5 元/百万 Tokens，实际账单以账号和当前官方报价为准 |
| 数据传输 | 完成权重下载后可本地处理，不必为编码将简历发往外部 | 编码输入发送到模型服务商；已有 LLM 调用不代表新增向量调用可以忽略数据范围确认 |

本地方案规格来自 [BGE 官方文档](https://bge-model.com/bge/bge_v1_v1.5.html)。模型使用方式及相似度阈值注意事项见 [BAAI 官方模型卡](https://huggingface.co/BAAI/bge-small-zh-v1.5)。接口规格、报价与调用示例见 [智谱官方 Embedding-3 文档](https://docs.bigmodel.cn/cn/guide/models/embedding/embedding-3)。

智谱页面概览标注 8K 上下文，同时技术参数对数组输入列出单条 3072 Tokens、最多 64 条。两处口径应在接入前用现行接口文档和测试核对，不能据概览直接上传整份长简历。长文本分段策略、长度校验和段落聚合都需要单独设计，不悄悄截断全文。

按该页面单价举例，若一次 20 份简历加 JD 的累计计费输入为 50000 Tokens，则编码成本约 `50000 / 1000000 × 0.5 = 0.025 元`。这是输入假设下的算术估算，不是本项目实际计费记录；重试、分段重叠和重新编码会改变总量。

## 最小对照评测

准备至少 30 组虚构 JD/简历，先由人工标注相关性与硬性要求是否满足。固定文本、模型版本、分段方式和随机种子；分别跑现有规则与候选向量方案，再比较排序，不能只展示三个主观成功案例。

| 场景 | 示例 | 关注点 |
|---|---|---|
| 同义表述 | JD 写“处理重复提交”，简历写“用唯一约束保证幂等” | 语义方案是否提高相关候选排序，同时保留可追溯原文 |
| 技能缺失 | JD 要求 Python/MySQL，简历只有泛化的“后端开发、团队协作” | 不能因行业语义相似就伪造技能命中，规则缺口仍须显示 |
| 不相关文本 | 后端 JD 对摄影、旅游、活动接待经历 | 比较相对排序和误报，不把单一相似度阈值当作能力结论 |

记录人工标注一致性、排序相关性、硬条件误判、冷/热耗时、峰值内存、失败率和输入成本。向量相似度不直接映射为百分比分数，先在本项目样本上校准；尤其要警惕“高相似度但硬条件缺失”。

## 建议与未完成项

建议在模拟面试联调完成后，单独做向量编码小实验。考虑服务器约 1.6GB 内存且已运行 OCR，优先在开发环境测本地小模型内存，或在明确数据传输范围后测现有服务商接口；目前没有证据表明哪种方案对本项目质量更好。

第一版实验只处理单批最多 50 份，不引入向量数据库；向量按模型版本和文本哈希缓存，失败回退现有基础评分。评测证明质量提升且资源与成本可接受后，再决定是否合入主链路。

**尚未完成：** 本机向量模型部署、远程向量接口实调、实际效果评测、延迟/内存/费用测量以及向量参与生产排序。这些不在今日面试接口交付中冒充完成。
